# Figures

The report figures are maintained once, in [docs/report/images/](../../docs/report/images/), together with their editable manuscript. The [mesh/](mesh/) subdirectory supplies nine additional native mesh views: wall-layer and interface details for M1, M2 and M3.

Native polygon edges are shown without adding artificial triangulation. The report captions identify inherited baseline-phase mesh views separately from the later restored-position Hybrid runs. Mesh-quality tables and distributions are documented in [mesh_quality/](../mesh_quality/README.md).
